# 🐟 摸鱼弹窗

> 把网页视频 / 小说，伪装成一个正儿八经的「Windows 系统弹窗」。
> 老板路过时，你只是在看一条系统警告，仅此而已。

一个用 C# (WinForms + WebView2) 写的桌面小工具。双击 exe 打开配置台，点一下「开始摸鱼」，桌面右下角就会弹出一个长得和系统弹窗一模一样的窗口——里面其实在播 B 站视频或看小说。

---

## ✨ 功能特性

- **10 款伪装皮肤**：Windows 安全中心、系统更新、磁盘空间不足、杀毒扫描、UAC 账户控制、网络错误、经典 XP 弹窗、Edge 安全拦截、任务计划、中奖广告
- **视频 / 网页小说双模式**：B 站 BV 号、YouTube、mp4 直链、本地视频；小说留空自动打开内置笔趣阁
- **完全贴合桌面角落**：右下 / 左下 / 右上 / 左上 / 居中，0 边距贴角，可拖动
- **3 档尺寸**：小 / 中 / 大
- **透明度可调**：50% ~ 100%
- **窗口置顶**：弹窗永远盖在其他窗口上面
- **可自定义热键**：紧急隐藏（默认 Esc，缩成桌面小绿点）、真退出（默认 Ctrl+Q）
- **伪装细节**：假进度条、假日志滚动、假扫描线，越看越真
- **单文件安装包**：0.97MB，一个 exe 自带全部运行文件，双击安装即用

## 🚀 快速开始

1. 下载安装包 `moyu-popup-setup.exe`（见 Release）
2. 双击运行 → 选择安装目录 → 点「开始安装」
3. 桌面出现「摸鱼弹窗」快捷方式，打开它
4. 地址留空直接点「开始摸鱼」→ 右下角弹出播放小窗

> 也可以不解压，直接在项目目录跑 `摸鱼弹窗.exe`（依赖同目录的 `fish.html`、`player.html`、`webview2\`）。

## 🎮 使用说明

| 配置项 | 说明 |
| --- | --- |
| 内容类型 | 视频 / 网页小说，切到小说模式后地址留空默认打开笔趣阁 |
| 地址 | B 站 BV 号、YouTube 链接、mp4 直链，或小说网页链接 |
| 本地文件 | 选择本地视频文件直接播放 |
| 伪装皮肤 | 10 款系统弹窗风格，见上 |
| 弹窗位置 / 尺寸 | 5 方位 × 3 档尺寸 |
| 窗口透明度 | 滑块调节 50%~100% |
| 窗口置顶 | 开启后弹窗始终在最前 |
| 紧急隐藏键 | 点击按钮后按下新组合键即可改，默认 Esc |
| 退出组合键 | 默认 Ctrl+Q |

## 🛠 实现原理

- **主程序**：C# (WinForms) + WebView2，`.NET Framework 4.0` 编译为单文件 exe
- **配置台**：`fish.html` 内嵌在 WebView2 主窗口，点「开始摸鱼」通过 `window.chrome.webview.postMessage` 通知宿主 C# 进程
- **弹窗**：C# 创建无边框 `Form`（0 边距贴角、圆角 Region、Opacity 透明度、TopMost 置顶），WebView2 载入 `player.html` 播放视频 / 嵌入小说页
- **高度自适应**：页面内容区通过 postMessage 上报实际高度，宿主动态调整窗体高度，杜绝空白
- **DPI 适配**：声明 Per-Monitor V2 感知，高分屏文字不发虚
- **安装包**：安装器把主程序 / 页面 / WebView2 运行库作为资源嵌入，运行时释放 + 创建桌面快捷方式

